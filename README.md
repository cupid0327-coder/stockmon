# STOCKMON — 年线破位监控系统

A 股 / 美股长线风控 + 短线择时的自动监控站点。**全链路确定性代码，不依赖任何大模型、零 API Key**——唯一外部依赖是新浪财经 / 东方财富 / 雅虎财经的免费行情接口。

浏览器里是一个会随市场状态呼吸的监控终端：巨字报价、双组信号徽章、真实走势背景场、警戒模式、盘中分时图。

## 功能总览

### 长线纪律（收盘轮确认，防风控失控）
- **年线破位四条件**：收盘跌破 MA250 + 量比 > 1.5 + 周线 MACD 死叉 → 破位第 1 天；连续 3 个收盘日站不回 → **有效破位**（减仓警示）
- **止赢三类**：放量滞涨 / 周线顶背离 / 跌破 10 日线（卖出提示）
- 盘中只预警不确认；双源价格互验（偏差 ≥0.5% 搁置结论）；节假日自动静默

### 加仓信号（收盘轮判定，买入提示）
- **站回年线 3 日确认**（与有效破位镜像）/ **回踩年线缩量企稳** / **放量突破 60 日新高**

### 短线策略（全部标的，买卖双向）
- **日线 MACD 金叉 / 死叉**：DIF 上穿 / 下穿 DEA
- **RSI(14) 超买超卖**：进入超卖区（买点提示）、离开（回升确认）、进入超买区（卖点提示）、离开（回落确认）

### 邮件通知
- 信号触发时按标的归属发送**摘要邮件**（多事件合并一封，不刷屏）
- SMTP 支持管理页可视化配置或环境变量；未配置时静默关闭

### Web 终端（原生 JS，无构建步骤）
- **仪表盘**：巨字报价、每行当日分时迷你图 + 距年线位置条、长线/短线双组徽章、市场多选筛选、真实走势背景场、有效破位全局警戒模式
- **个股详情**：盘中分时图（昨收基准、60 秒刷新）、140 日平滑收盘图（MA5/MA10/年线 + 量柱 + 年线事件标记 + 十字线悬停）、三组数据卡（股票信息/长线/短线）、事件时间线
- **多用户**：注册 → 管理员审核 → 角色升降级；SMTP 管理页可视化配置；修改密码 + 通知邮箱

## 架构

```
浏览器(手机/PC 响应式) ──HTTP──▶ FastAPI(单进程, systemd 托管)
                                   ├─ 静态前端（原生 JS + 内嵌 Lucide 图标/字体）
                                   ├─ REST API（认证 + 自选 + 仪表盘 + 分时 + 事件）
                                   ├─ 调度线程：每 5 分钟
                                   │   ① DB → 生成基线 JSON
                                   │   ② subprocess 运行检测器
                                   │   ③ 事件入库（按用户归属）→ 邮件摘要
                                   └─ SQLite (webapp/data/stockmon.db)
```

检测器与 Web 层完全解耦：`a_share_breakdown.py` 可独立运行，调度仅通过环境变量传入路径与状态文件。

## 快速开始

```bash
pip install -r webapp/requirements.txt
python -m uvicorn webapp.app:app --host 127.0.0.1 --port 8100
# 浏览器打开 http://127.0.0.1:8100 → 注册（首个用户自动成为管理员）→ 添加自选
```

- Windows 需 `pip install tzdata`；Linux 自带
- 添加自选：A 股输代码（600000 / 002008），指数从目录点选（含上证 B 股、北证 50），美股输代码（NVDA），美股指数（DJI / IXIC / SPX / SOX）
- 添加时自动拉取日K计算 MA250 与周线 MACD；盘中分时图自动启用

## 监控范围与数据源

| 类型 | 覆盖 | 数据源 |
|---|---|---|
| A 股个股 / 指数（含 B 股指数、北证 50） | 全部常用指数目录点选 | 新浪（报价/分时）+ 东财（日K/量比/估值/市值） |
| 美股个股 | NASDAQ / NYSE / AMEX | 同上 |
| 美股指数 | 道琼斯 / 纳斯达克 / 标普500 / 费城半导体 | 费半日K多级回退：雅虎 ^SOX → 东财 SMH → 腾讯 SMH（代理重标定，已知近似，见下） |

**SOX 代理说明**：雅虎不可达时基线与分时按 SMH（VanEck 半导体 ETF）计算并将 MA250 按实时比值重标定到 SOX 指数标度，隐含"SOX/SMH 比值恒定"假设，属于已知近似并在界面标注。

## 配置（环境变量）

| 变量 | 默认 | 说明 |
|---|---|---|
| `STOCKMON_DATA_DIR` | `webapp/data` | SQLite / 基线 / 检测器状态目录（备份 = 复制它） |
| `STOCKMON_POLL_INTERVAL` | `300` | 调度间隔（秒） |
| `STOCKMON_INTRADAY_REFRESH` | `60` | 盘中分时图前端刷新间隔（秒） |
| `STOCKMON_REGISTRATION_OPEN` | `1` | 设为 `0` 关闭注册 |
| `STOCKMON_SMTP_*` | 空 | 邮件通知（HOST/PORT/USER/PASS/MAIL_FROM/TLS），详见 `webapp/README.md` |
| `BREAKDOWN_BASELINE_DIR` / `BREAKDOWN_STATE_PATH` | data 目录 | 检测器路径覆盖（自动设置） |

## 信号口径速查

| 信号 | 条件 |
|---|---|
| 破位第 1 天 | 收盘跌破 MA250 + 量比>1.5 + 周线死叉（缺则"待确认"） |
| 有效破位 | 连续 3 个收盘日站不回 |
| 止赢 | 放量滞涨 > 周线顶背离 > 跌破10日线（优先级取一） |
| 加仓 | 站回年线3日确认 / 回踩缩量企稳 / 放量突破60日新高 |
| 短线买点 | 日线MACD金叉 / RSI进入超卖 / 离开超卖回升 |
| 短线卖点 | 日线MACD死叉 / RSI进入超买 / 离开超买回落 |

所有信号：收盘轮判定、去重后提醒、不自动交易、仅供参考不构成投资建议。

systemd 单实例 + nginx 反代 + certbot HTTPS 的完整步骤见 [`webapp/README.md`](webapp/README.md)。要点：**必须单 worker**（调度线程在进程内）、OCI 安全列表放行 80/443、邮件 SMTP 也可在管理页直接配置（存库，优先于环境变量）。
